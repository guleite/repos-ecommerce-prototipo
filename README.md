# Repós Cosméticos — Protótipo de e-commerce B2C/B2B

Protótipo de layout para apresentação. Ao abrir o site, um pop-up pergunta se a pessoa compra como **Pessoa Física** ou **Pessoa Jurídica**, e preços, condições, recomendações e páginas de produto mudam conforme o perfil.

## Como abrir
- **Arquivo único:** `Repos-Ecommerce-Prototipo.html` (imagens, CSS e JS embutidos).
- **Fontes:** `index.html`, `css/style.css`, `js/data.js` (produtos e preços), `js/app.js` (lógica), `assets/img/`.

## Observações
Preços, avaliações, depoimentos, rendimentos e alguns tamanhos são ilustrativos. O checkout não está incluído.
